# Manta control centre (Qt front end, 1.0.0)

`python frontend/manta_control.py` (or `frontend/run_manta_control.cmd`, or the PyInstaller build `python frontend/build_release.py` -> `dist/MantaControl/MantaControl.exe`; PySide6 required for the script).
It builds the emulator command line from `configs/frontend/profile-original.json` (the hardware/hypothesis flags of the stock desktop launcher, generated by `frontend/make_profile.py`) plus the
settings you choose, starts the emulator with `--frontend-shm` (protocol: `frontend-protocol.md`), shows the picture and sends remote keys.

* **Firmware**: any SPI image; the SHA-256 is compared with the verified original. A different image runs on the interpreter from a cold boot (saved states and the recompiled native engine only exist for the stock image).
* **Start-up**: resume a saved machine state (`work/checkpoints/*.snap`, seconds) or cold boot (the interpreter reaches the UI in a few minutes).
* **Machine**: guest clock (cycles per instruction, an uncalibrated time scale: 16 = the setting of the saved states, 2 = about 3x faster emulation), RAM (second DRAM bank 0..352 MB, MIU0 fixed at 128 MB; non-stock sizes need a
  cold boot), PM51 and co-processor dispatch dividers (hypothetical ratios), run length, NVRAM overlay, extra emulator options.
* **Picture**: exploratory video plane colour, black colour key (off / edge-only / all black), frame-rate cap, optional ATV test picture behind the OSD (exploratory PAL colour bars; off in menus if you prefer a plain background).
* **Remote**: model of the real remote (layout from a photo). Keyboard mode: every key shows its binding (yellow badge); mouse mode: click the keys. Dotted keys have no verified IR code for the original firmware yet
  (`configs/input/ir-keymap.tsv` holds only evidence-backed codes, see `ir-key-semantics.md`); they are still sent and logged as undeliverable. K / N / B open the on-screen keyboard, network and browser pages (native engine).
* Pause/resume (Ctrl+P), screenshot (Ctrl+S) / copy (Ctrl+C), full screen (F11), always on top, scale modes, machine profiles (File menu), log dock (View).

Speed (headless, snapshot state, this PC): the 8051 co-processor models dominated the run time; the instruction length now comes from a table instead of formatted disassembly (summaries byte-identical): 6.4 -> 12.2 M dispatches/s
at 16 cycles per instruction; 31 M/s at 4 and 39 M/s at 2 (less co-processor work per dispatch). Live picture: composed only when the GOP memory changed, capped by wall time (`--preview-max-fps`).
Tools: `frontend/bench.py` (speed), `tools/host_profile.py` (which host functions burn the time), `tools/key_sweep_native.py` + `tools/make_dtv_state.py` (single-key sweeps), `frontend/grab_ui.py` / `selftest.py`.
